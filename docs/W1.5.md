# 三、错误分层

```text
HTTP / 连接层
→ ClientConnectionException

I/O / 通信层
→ IOException

JSON-RPC 层
→ response.hasError()

结果完整性
→ result 缺失 / 非法

业务校验层
→ RPC 正常，但返回值不符合系统要求
```

`send()` 直接抛异常，与 `send()` 成功得到 Response 但 `hasError() == true` 是两条不同错误路径。

JSON-RPC 错误可读取：

```java
error.getCode();
error.getMessage();
error.getData();
```

错误分层会直接影响后续 Retry、Backoff、停止扫描等策略，因此不能全部用一个 `catch (Exception)` 吞掉。
