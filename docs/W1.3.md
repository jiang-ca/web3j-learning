# W1.3｜请求对象与响应对象

状态：✅ 已通过

# 一、本节目标

拆开 `ethBlockNumber().send()`，直接观察 Request、JSON-RPC 请求、原始响应和 Java 响应对象之间的关系。

# 二、示例代码

源码：

```text
src/main/java/com/example/web3jstudy/w1/RequestResponseDemo.java
```

核心代码：

```java
Request<?, EthBlockNumber> request = web3j.ethBlockNumber();
EthBlockNumber response = request.send();
```

请求 JSON 结构：

```json
{
  "jsonrpc": "2.0",
  "method": "eth_blockNumber",
  "params": [],
  "id": 0
}
```

# 三、Request 的核心字段

```text
jsonrpc  → JSON-RPC 协议版本
method   → RPC 方法
params   → 方法参数
id       → 请求与响应的对应标识
```

Request ID 不是 Chain ID、交易哈希或业务幂等键。

`Request<?, EthBlockNumber>` 中第二个泛型表示本次请求预期解析成 `EthBlockNumber` 响应类型。

# 四、Response 的核心内容

```java
response.getRawResponse();
response.getResult();
response.getBlockNumber();
```

分别表示：

```text
完整 JSON 响应正文
result 字段
result 解码后的区块号
```

这些数据都来自同一次 RPC 请求。
