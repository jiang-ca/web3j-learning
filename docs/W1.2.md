# 一、本节目标

理解 `Web3j` 与 `HttpService` 的职责分工，并复用同一个客户端执行多次独立 RPC 查询。

# 二、示例代码

源码：

```text
src/main/java/com/example/web3jstudy/ClientServiceDemo.java
```

核心结构：

```java
HttpService httpService = new HttpService(rpcUrl);
Web3j web3j = Web3j.build(httpService);

web3j.ethChainId().send();
web3j.ethBlockNumber().send();
```

# 三、核心知识

`Web3j` 负责提供 RPC 方法并构造请求。

`HttpService` 负责通过 HTTP 把请求发送到配置的 RPC Endpoint。

不同 RPC 方法通常仍发往同一个 Endpoint，变化的是 JSON-RPC 请求中的 `method` 和 `params`。

复用同一个 `Web3j` 客户端，不代表复用上一次查询结果；每次 `.send()` 仍然是独立 RPC 调用。

客户端复用也不等于所有请求永远使用同一条 TCP 连接；底层 HTTP 客户端负责连接池和连接复用。
