# 一、本节目标

使用同一个 Web3j 客户端查询三项基础节点信息：

```text
eth_chainId
eth_blockNumber
web3_clientVersion
```

# 二、示例代码

源码：

```text
src/main/java/com/example/web3jstudy/w1/BasicNodeInfoDemo.java
```

# 三、三个查询分别表示什么

`eth_chainId`

→ RPC 节点报告的网络标识。

`eth_blockNumber`

→ RPC 节点当前看到的最新区块高度。

`web3_clientVersion`

→ 远端 RPC 节点报告的客户端软件信息，不是 Maven 中的 Web3j 版本。

这三个调用复用同一个 Web3j 客户端，但仍然是三次独立 RPC 请求，不是 JSON-RPC Batch。
