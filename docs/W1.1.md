# W1.1｜查询 Chain ID，核对目标网络

状态：✅ 已通过

# 一、本节目标

调用 `eth_chainId` 查询 RPC 节点报告的 Chain ID，并与业务预期的 BSC 主网进行校验。

BSC Mainnet：

```text
Chain ID = 56
Hex      = 0x38
```

# 二、示例代码

源码：

```text
src/main/java/com/example/web3jstudy/ChainIdDemo.java
```

核心调用：

```java
EthChainId response = web3j.ethChainId().send();
BigInteger actualChainId = response.getChainId();
```

# 三、核心知识

`ethChainId()` 对应 JSON-RPC 方法 `eth_chainId`。

`response.getResult()` 可得到原始值，例如 `0x38`。

`response.getChainId()` 将其解码为 `BigInteger(56)`。

本地的 `expectedChainId` 只用于校验，不会切换 RPC 所连接的网络。

Chain ID 校验可以发现网络配置错误，但它只是节点报告的网络标识，并不等于对 RPC 服务全部返回数据进行可信证明。
