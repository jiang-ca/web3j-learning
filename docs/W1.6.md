# W1.6｜同步与异步调用

状态：✅ 已通过

# 一、本节目标

理解 Web3j 的同步调用 `.send()` 与异步调用 `.sendAsync()` 的差别。

# 二、示例代码

源码：

```text
src/main/java/com/example/web3jstudy/w1/SyncAsyncDemo.java
```

# 三、同步调用

```java
EthBlockNumber response =
        web3j.ethBlockNumber().send();
```

执行到 `.send()` 时，当前线程等待 RPC 返回后才继续执行。

# 四、异步调用

```java
CompletableFuture<EthChainId> future =
        web3j.ethChainId().sendAsync();
```

`sendAsync()` 返回 `CompletableFuture`，RPC 在异步任务中执行，当前线程可以继续处理其他逻辑。

需要结果时可以：

```java
future.join();
```

多个互不依赖的异步请求可以先全部提交，再用：

```java
CompletableFuture.allOf(...).join();
```

等待全部完成。

# 五、关键边界

异步不是“永远不阻塞”，而是把等待点从发送位置移动到真正需要结果的位置。

异步也不等于 JSON-RPC Batch；多个 `sendAsync()` 仍然是多个独立 RPC 请求。

异步任务失败时，异常会进入 `CompletableFuture`，`join()` 时通常以 `CompletionException` 暴露。

运行 `SyncAsyncDemo.main()`，确认同步和异步两部分都正常输出。
