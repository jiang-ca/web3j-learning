状态：✅ 已通过

# 一、本节目标

通过 Web3j 调用 BSC RPC 的 `eth_blockNumber`，完成第一次只读查询，并理解请求地址、发送请求和结果解码之间的关系。

# 二、示例代码

源码：

```text
src/main/java/com/example/web3jstudy/FirstRpcDemo.java
```

核心调用：

```java
Web3j web3j = Web3j.build(new HttpService(rpcUrl));
EthBlockNumber response = web3j.ethBlockNumber().send();

System.out.println("原始结果：" + response.getResult());
System.out.println("最新区块号：" + response.getBlockNumber());
```

# 三、核心知识

`rpcUrl` 指定 RPC 服务入口；这个入口对应目标网络。

`ethBlockNumber()` 构造 `eth_blockNumber` 请求。

`.send()` 真正发送 RPC 请求并等待响应。

`getResult()` 读取原始十六进制结果。

`getBlockNumber()` 在本地把结果解码为 `BigInteger`，不会再次请求 RPC。
